وب‌سایت شخصی جواد حسینی
========================

فایل index.html را در مرورگر باز کن یا کل پوشه را روی GitHub Pages منتشر کن.

موسیقی:
- فایل انتخابی شما در assets/background.mp3 قرار گرفته است.
- به‌خاطر محدودیت مرورگرها، پخش خودکار صدا معمولاً بدون لمس کاربر مجاز نیست؛ دکمه پخش پایین صفحه را بزن.

عکس‌ها:
- یک پوشه به نام images بساز (در نسخه نهایی همین پوشه کنار index.html قرار می‌گیرد).
- عکس‌ها را با نام‌های زیر داخل آن قرار بده:
  photo-01.jpg تا photo-11.jpg
- عکس اصلی صفحه اول فعلاً جایگاه آماده دارد و بعد از انتخاب تصویر نهایی، با عکس منتخب جایگزین می‌شود.

انتشار روی GitHub Pages:
1) فایل‌های index.html، style.css، script.js و پوشه assets را در ریشه مخزن قرار بده.
2) پوشه images را هم اضافه کن.
3) در Settings > Pages، انتشار از شاخه main و پوشه /(root) را فعال کن.

فونت‌ها از Google Fonts بارگذاری می‌شوند؛ برای نمایش آن‌ها اینترنت لازم است.
